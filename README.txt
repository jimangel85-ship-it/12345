同伴 CRM — 20 人帳號版

需要 Node.js 24.22.1 或相容且支援 node:sqlite 的版本。
在此資料夾執行 node server.cjs，再開啟 http://localhost:4173。
此版本需要伺服器，無法直接開啟 index.html 使用。
具備：客戶新增／編輯／搜尋／負責人與狀態篩選、商機新增與階段更新、待辦新增與完成、客戶聯繫紀錄、資料匯出。
頁面同時支援手機與桌面尺寸。

帳號配置：共 20 人，1 位主管 manager01、19 位一般同事 staff01 到 staff19。
首次啟動會產生 private/initial-accounts.csv，每個人都有不同的隨機初始密碼。
這份清單包含全員初始密碼，僅限主管保管，請分別把各人的那一列私下提供本人。
首次登入必須更換至少 12 字元的密碼。更換密碼後，全部裝置登出。
清單不會隨改密碼更新；請在完成發放後由主管安全保管或移除。

主管：查看及編輯全隊客戶、商機、待辦與紀錄；分派客戶和待辦；管理帳號顯示名稱、角色、啟用狀態與重設密碼；查看最近操作。
一般同事：新增與管理自己的客戶、商機、聯繫紀錄及待辦；可完成主管指派給自己的待辦。
被指派其他人的客戶待辦時，只看到該待辦內容，不會取得客戶聯絡資料或商機／留言的存取權。
只有主管可以將客戶或待辦分配給其他人。不能停用或降級自己的主管帳號。
主管可把其他帳號改成主管，因此可調整主管人數，總帳號維持 20 個。
重設密碼會使舊密碼立即失效，新密碼只顯示一次，需私下交給本人。
角色變更、停用與密碼重設會撤銷該帳號的所有登入狀態。

資料儲存在伺服器的 private/crm.sqlite。所有使用者連到同一台伺服器時共用資料；每 30 秒更新，也可按「重新整理」。
同時編輯同一筆資料時會拒絕較舊的版本，請重新開啟編輯後再儲存。
請備份整個 private 資料夾；備份前先停止伺服器，以確保 SQLite WAL 資料完整。
登入狀態有效期為 8 小時；伺服器只儲存密碼雜湊與登入 token 雜湊。帳密清單例外保留初始密碼供發放。
前端匯出只包含該帳號有權查看的資料，不包含帳密或其他人的客戶。

舊版資料仍在原先瀏覽器的 localStorage，系統不會自動上傳。
主管可在「帳號管理 → 匯入本機舊版資料」確認後匯入，僅限伺服器尚無資料時一次執行。
對應：「我」→目前主管；「小安」→staff01；「佳穎」→staff02；其他名稱→目前主管。匯入後可再分配與更改同事顯示名稱。
請使用舊版的相同網址（localhost 和 127.0.0.1 各自的瀏覽器資料不同）與瀏覽器匯入。匯入後舊資料仍保留。

此版本是本機測試用手機網頁，尚未部署上線，也不是 Android / iOS 安裝套件，尚無背景通知。
字型連線失敗時會使用系統字型，其餘功能不需網路。

預設只接受電腦本機存取，並檢查 Host、Origin 與 CSRF token。
正式提供同事跨裝置使用前，需要部署到團隊可存取的主機與 HTTPS 網域。
部署時設定 APP_ORIGIN 為確切的 https://網域；HTTPS 設定會開啟 Secure cookie。
若在受信任的同一 Wi-Fi 以虛構資料測試，可以在 PowerShell 設定：
$env:BIND_HOST='0.0.0.0'
$env:APP_ORIGIN='http://localhost:4173,http://電腦區網IP:4173'
node server.cjs
再由手機開啟 http://電腦區網IP:4173。區網 HTTP 沒有傳輸加密，請僅用於測試。
請勿把 private 資料夾放到網站靜態目錄，或把初始帳密清單傳給所有同事。

工作總覽的團隊公告：主管可發布、編輯與置頂公告，全體登入同事可閱讀並在各公告下留言。每筆公告及留言由伺服器記錄真實登入作者與時間。
置頂公告優先顯示，首頁預設顯示 3 則，可展開全部。點「閱讀全文與留言」開啟完整內容與討論串。
留言建立後不可修改，需補充時可新增留言。一般同事無法發布或編輯公告。
公告與留言保存在同一個 SQLite 資料庫，與工作台一起每 30 秒更新；按「重新整理」可立即讀取最新內容。開啟中的討論串請關閉重開以查看新留言。
公告和留言的文字欄位也支援語音輸入，仍需使用者確認文字後按發布或送出。

工作日誌：登入後進入「工作日誌」，可新增工作日期、標題、關聯客戶（選填）、工作內容與成果、下一步與待協助事項。
一般同事只能查看及編輯自己的日誌；主管可查看全隊日誌，但不能代改其他人的內容。支援日期、同事及關鍵字篩選。
日誌的「下一步」只是記錄，不會自動新增待辦；需要提醒時請另建跟進待辦。
日誌保存在同一個 SQLite 資料庫，包含於該登入者有權匯出的 JSON 資料。

語音輸入：客戶名稱、聯絡人、電話、產業、商機名稱、待辦內容、聯繫紀錄與工作日誌文字欄位旁提供「語音輸入」。
點選後先閱讀說明，再按「開始收音」，由本人允許麥克風權限。支援國語（台灣）與英文選擇。
說完按「停止收音」，檢查／修改辨識文字，再按「填入欄位」，最後按表單的儲存按鈕。
填入會保留原文並附加新文字，不會自動儲存；單次收音上限 60 秒，取消、切換頁面或關閉表單會中止收音。
日期、金額、負責人與狀態請手動選填，避免語音誤判。
使用瀏覽器的 SpeechRecognition / webkitSpeechRecognition，需瀏覽器及裝置支援、可用麥克風與 HTTPS（localhost 可本機測試）。
本機內嵌瀏覽器可能不提供辨識服務；若無法使用，可改用手機系統鍵盤的麥克風，或支援語音辨識的一般瀏覽器。
瀏覽器可能將語音傳送給其辨識服務，因此可能需要網路；本系統不儲存音檔，也沒有另外串接付費轉錄 API。
語音說明與相容性參考：https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition
